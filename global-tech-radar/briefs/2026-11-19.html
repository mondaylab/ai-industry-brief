Qwen4-Max 正式发布

阿里发布 Qwen4-Max。官方披露总参数 2.4 万亿，支持原生视觉输入，标称上下文为 100 万 token。

美国 · API 已开放

GPT-6.2 Astra 与 Sol 同时开放

OpenAI 同时推出面向高难度项目的 Astra 和面向日常 Agent 工作流的 Sol。两个模型都接收文本与图像输入，并输出文本。

影响 同一工作流可以先对常规任务使用 Sol，再对高难度任务验证 Astra 升档是否带来净收益。

验证与限制 API 支持 Responses 与 Chat Completions。调用工具需要使用 Responses API，迁移时应核对接口差异。

  • OpenAI 发布公告 ↗ 2026-11-17 · 官方公告

美国 · 分批推出

Gemini 4 Neon 开始推出

Google 开始在 Gemini API、企业产品和部分付费用户入口提供 Gemini 4 Neon。官方公布百万 token 上下文，并将其定位在 Carbon 和 Hydrogen 之间。

影响 对编程和分析任务，可以把 Neon 加入按延迟和质量分层的模型路由测试。

验证与限制 不同入口的套餐和可用范围不同。端到端比较时应固定推理档位，并单独记录首 token 延迟与任务完成时间。

评测Evaluations

跨地区 · 公开榜单

Terminal-Bench 记录 Astra 与 Sol 的完成率和成本

Terminal-Bench 4.1 记录 GPT-6.2 Astra（max）搭配 Codex 的解决率为 62.1% ± 2.3%，Sol（max）搭配 Codex 为 61.5% ± 2.8%。榜单所列成本约为 1,400 与 300 美元。

影响 对这组终端任务，Sol 值得作为成本基线，再看 Astra 能否提高自有任务的成功交付率。

验证与限制 两项成绩的区间重叠。成本是榜单显示的舍入值。两行的模型发布日期均为 11 月 17 日，榜单于 11 月 19 日查阅。

  • Terminal-Bench 4.1 榜单 ↗ 2026-11-19 · 榜单快照

独立评测补齐 Qwen4 Max 的任务成本

美国 · 正式可用

Gemini Enterprise 的 A2A 用户委托授权正式可用

Google 为运行在 Agent Runtime 的 ADK 智能体开放三方 OAuth。需要授权时，Gemini Enterprise 获取当前用户同意，随后恢复 A2A 会话。

影响 企业 Agent 可以按登录用户的权限调用下游 MCP 服务或第三方 API，便于把授权纳入原有工作流。

验证与限制 公告适用于指定的 ADK 与 Agent Runtime 组合。上线前应单测拒绝授权、撤销授权和过期令牌。

混元 Hy4 flash 开放权重并披露缓存复用架构

腾讯在 Hy4 flash 公布混合注意力、LatentMoE 和 Engram 设计。用于投机解码的 DFly2 复用目标模型的 KV 缓存与稀疏索引。

跨地区开源 · 迁移进行中

SGLang 1.0 计划切换至 sgl-router

SGLang 1.0 的发布追踪将 sgl-router 列为旧网关的替代方案。11 月 17 日的维护讨论提出补齐前后命令对照、预填充与解码分离和缓存感知路由的迁移样例。

影响 依赖旧网关启动参数的部署可提前盘点配置，并为切换后的服务发现与路由行为保留回归样本。

验证与限制 独立路由器已有版本，1.0 迁移清单仍在推进，应以正式兼容表和目标硬件测试为准。

编辑判断

同一模型的综合评测、真实工具任务和线上吞吐回答的是三类问题。第一轮选型可以固定任务、工具权限和失败重试策略，记录成功交付率、每次成功交付成本与 P95 耗时，再决定哪些任务需要升级到更强模型。

接下来验证

  • 在自有仓库，用同一批有验收脚本的任务比较 Astra 与 Sol，保留超时、重试、工具调用和人工返工成本。
  • 跟进 Hy4 flash 在长上下文并发条件下的第三方实测，记录硬件、量化版本、输入长度和 P95 首 token 延迟。
  • 跟进 SGLang 1.0 的正式迁移文档，核对现网使用的命令行参数与缓存感知路由的兼容性。
