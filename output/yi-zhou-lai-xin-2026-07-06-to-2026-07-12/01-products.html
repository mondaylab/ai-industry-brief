产品前线
AI 正在进入常用软件

这周最值得看的产品变化：AI 被放进会议、设计、代码、文件和家庭自动化这些日常入口。

07.06cursor.com

Cursor iOS 手机跑 Agent

Cursor 把云端 Agent 搬到了 iPhone 上，用户可以用手机派发代码任务并合并 PR。代码 Agent 开始脱离 IDE，进入随时可调用的移动入口。

07.07slack.com

Slackbot 增加记忆和语音动作

Slackbot 新增长期记忆、MCP 连接和语音操作，可以在对话里连续处理工作。Slack 正把聊天机器人升级成常驻协作空间的个人 AI Agent。

07.08businesswire.com

Sourcegraph 发布 Agentic Batch Changes 公测

Sourcegraph 开放 Agentic Batch Changes 公测，让 Agent 批量修改大型代码库并保留审查流程。代码 Agent 的价值开始从写一个函数，扩展到执行跨仓库工程任务。

07.08cloud.google.com

Gemini Enterprise 细化 Agent 平台选型

Google Cloud 梳理了 Gemini Enterprise 旗下四套 Agent 开发方案及其适用场景。企业采用 Agent 的难题，正转向如何选择合适的方式把它接进现有系统。

07.09openai.com

OpenAI 发布 GPT-Live 语音模型

OpenAI 发布 GPT-Live，主打低延迟、可自然打断的实时语音对话。语音模型正从朗读答案，走向能接住真实交流节奏的对话入口。

07.12businesswire.com

Workato 发布 Headless API 和 Agent Guardrails

Workato 为 Agent Studio 增加 Headless API 和运行护栏，让业务应用直接嵌入受约束的 Agent。企业对 Agent 的需求，正从聊天入口转向可嵌入、可约束的执行能力。

07.12prnewswire.com

Omneky 发布广告生成 API 和 MCP Server

Omneky 开放广告生成 API 和 MCP Server，让平台与 AI Agent 直接调用创意引擎。广告生成正在从独立工具变成其他工作流可以随时调用的基础能力。

07.12businesswire.com

ZoomInfo 发布 GTM Bench 评测销售 AI

ZoomInfo 发布 GTM Bench，用真实获客和销售任务评估 AI Agent。销售 AI 的评测标准，正在从对话表现转向真实任务完成度。
